# Essays

Speculative writing. **Not project architecture, not a roadmap, and not a description of
anything KungFu does or intends to do.**

These were written alongside the project's early design work and are kept because the thinking
was worth keeping. They are explicitly separated from the technical documentation so nobody
mistakes them for it. The design of KungFu is in the root [README](../README.md), and nothing
in this folder governs it.
